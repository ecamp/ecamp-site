---
title: Does eCamp v3 support the new Y+S education system 2027?
---

Yes. There is a dedicated camp template for Y+S camps from 2027 onwards. With the "Y+S activity characteristics" content block, you can select the characteristics (Erscheinungsformen) covered in each activity, and with the "Y+S physical activity time" content block, you can record the physical activity time (Bewegungszeit) for each schedule entry of an activity. The physical activity time can also be shown in the program overview (Grobprogramm).<br/>
If you have already created your camp using a different camp template, you can add both content blocks to your activities afterwards. To have them included automatically in new activities, add them to the "Template for new activities" of the respective category under Admin → Activities.
